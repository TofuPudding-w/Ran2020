# ran2020 MPD Algorithm README

本项目是 2020 年矩阵乘积解缠器（Matrix Product Disentangler, MPD）算法的实现，用于对量子多体态进行逐层解缠编码，逐步降低量子态的纠缠程度，将高纠缠的多体量子态转化为接近乘积态的形式，可用于抑制量子蒙特卡洛的符号问题，或量子态的高效编码。

## 目录结构

```Plain Text
ran2020/
├── main.py                # 项目入口脚本，运行完整的解缠实验
├── ran2020.py             # MPS核心操作模块，包含正交压缩、解缠算符构建等
├── mpd.py                 # MPD算法核心实现，包含完整的编码算法流程
└── outputs/               # 实验输出目录，保存结果图像
```

## 环境依赖

项目需要 Python 3\.8 及以上版本，依赖以下 Python 库：

```bash
pip install numpy scipy matplotlib tenpy ncon
```

## 快速开始

直接运行入口脚本即可完成完整的实验流程：

```bash
python main.py
```

脚本会自动完成以下步骤：

1. 使用 TeNPy 的 DMRG 算法，计算 24 格点一维海森堡模型的基态

2. 运行 MPD 编码算法，逐层对基态进行解缠

3. 计算每一层的负对数保真度（NLF），衡量纠缠的下降程度

4. 绘制 NLF 随电路层数的变化曲线，保存到`outputs/`目录下

## 实验细节

### 算法原理

矩阵乘积解缠器（MPD）是一种逐层的量子解缠算法，能够通过局部的量子门，逐步消除多体量子态的纠缠，将高纠缠的量子态转化为乘积态：

1. **MPS 表示**：将量子多体态表示为矩阵乘积态（MPS），这是一维量子多体态的高效表示方式

2. **逐层解缠**：每一层，我们根据当前 MPS 的信息，构建一层局部的解缠量子门，这些门能够消除当前的主要纠缠分量

3. **迭代优化**：重复解缠过程，每一层都会进一步降低量子态的纠缠，直到量子态接近乘积态

### 核心指标：负对数保真度（NLF）

我们使用负对数保真度（Negative Log Fidelity, NLF）来衡量量子态的纠缠程度：

NLF 越小，说明当前量子态越接近全零乘积态，纠缠程度越低。理想情况下，随着解缠层数的增加，NLF 会指数下降。

### 模型与参数

本实验默认使用 24 格点的一维海森堡模型，参数如下：

- 系统大小：N=24

- 最大虚拟维度：chi\_max=256

- 最大解缠层数：D\_max=8

- 物理维度：d=2（自旋 1/2 系统）

## 实验结果

实验会输出每一层的 NLF 变化，最终生成的图像会展示：

- 蓝色曲线：每一层解缠后的 NLF，随着层数增加，NLF 会逐步下降

- 红色虚线：全局纠缠的理论下界，也就是完全解缠后的 NLF 最小值

实验表明，MPD 算法能够在仅 8 层的量子线路内，将海森堡基态的纠缠降低一个数量级以上，证明了算法的有效性。
